# Rhythm Changes Chord Permutation Generator

This is a quick project I set up to quickly generate random sets of chord progressions of the first 8 bars of rhythm changes. The sets are intended to provide practice progressions for comping and improvisation.

I used ChatGPT to help generate the progressions. I make no claims to accuracy; they are what they are so use this at your own risk.

### How to Run

```
python3 rhythm_changes.py
```
